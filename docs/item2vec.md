# Item2Vec 面试问答

## 基础理解

### Q: Item2Vec 和 Word2Vec 什么关系？

直接迁移。把用户点击序列当作句子，物品 ID 当作词，用 Skip-Gram 训练。核心假设是：被同一批用户在相近时间内点击的物品，语义相似。

### Q: 为什么用 Skip-Gram 而不是 CBOW？

Skip-Gram 用中心词预测上下文，适合学稀疏物品的向量，每个词都能更新向量；CBOW 用上下文预测中心词，适合高频词， 高频词的向量被更新得多。推荐场景中长尾物品多（大部分物品点击量很少），Skip-Gram 对低频物品效果更好。

### Q：详细讲讲负采样：
防止softmax灾难，采样负样本，最大正样本输出 最小负样本输出，使用样本频率进行采样，抑制一些频率少的样本噪声，同时使用3/4幂限制过多采样频率高的样本

## 原理深入

### Q: 和 ItemCF 的本质区别是什么？

| | ItemCF | Item2Vec |
|---|---|---|
| 物品关系 | 离散共现计数 | 连续向量空间 |
| 泛化能力 | 只能召回与历史物品直接共现的 | 能召回间接相关的（向量空间中的近邻） |
| 计算方式 | 构建 i2i 矩阵，O(N²) | 训练 W2V + FAISS 检索 |
| 可解释性 | 强（"A 和 B 被 100 人共同点击"） | 弱（只知道向量接近） |
| 冷启动 | 新物品无共现记录则无法召回 | 新物品只要出现在训练序列中就有向量 |

ItemCF 是**显式共现统计**——只能发现直接关联。Item2Vec 是**隐式向量表示**——能泛化到没有直接共现但语义相近的物品。比如 A 和 B 没有共同用户点击过，但 A 和 C 相似、C 和 B 相似，在向量空间中 A 和 B 可能也会接近。

### Q: 负采样是什么？为什么需要？

Skip-Gram 的原始目标是 softmax over 全部物品（36 万），计算量太大。负采样把它简化为二分类：从窗口内取正样本（真实的上下文物品），再随机采样几个负样本（不是上下文的物品），训练模型区分两者。`negative=5` 表示每个正样本对应 5 个负样本。

## 工程实现

### Q: 为什么用 FAISS 而不是直接 numpy 算？

暴力搜索要算 36 万次余弦相似度，numpy 做矩阵乘法虽然也是向量化但没有 SIMD 优化。FAISS 是 Facebook 专门为向量检索优化的库，内部用 BLAS + SIMD，同样精确搜索比 numpy 快很多。如果物品量到千万级还可以换近似索引（IVF、HNSW）。

### Q: 为什么 L2 归一化后用内积索引？

两个 L2 归一化后的向量，内积 = 余弦相似度。这样用 `IndexFlatIP` 就等价于余弦相似度搜索，而且 FAISS 的内积实现比手写 cosine 更快。
