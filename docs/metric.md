# 推荐系统的评价指标篇

## 召回：命中率 MRR（平均倒数排名）
- 命中率 = 命中/总数
- MRR = 排名倒数和/总数

## 排序：AUC NDCG
- AUC：随机抽一个正样本和一个负样本，模型给正样本的分数高于负样本的概率。衡量模型把正样本排在负样本前面的能力 ROC曲线下与坐标轴围成的面积
- NDCG：按模型排序后，正确答案的累积增益占理想排序的比例。位置越靠后折扣越大（1/log2(i+2)），范围[0,1]

## 面试高频问题

### Q1: Recall 和 MRR 的区别？
Recall 只看"有没有召回正确答案"，MRR 还看"排第几"。召回阶段更关注 Recall（覆盖率为王），但 MRR 也能反映召回质量。

### Q2: 为什么召回用 Recall@K，排序用 NDCG@K？
召回阶段目标是"不漏"，所以看覆盖率。排序阶段目标是"排准"，所以看位置质量。两阶段关注点不同，指标不同。

### Q3: 为什么不用 Accuracy 而用 AUC？
1. Accuracy 依赖阈值，换阈值结果不同
2. 推荐场景正负比 1:1000，全猜负就有 99.9% accuracy，但没用
3. AUC 不需要选阈值，不受正负比例影响

### Q4: AUC 和 NDCG 的区别？
AUC 衡量全局区分能力，正样本排第 1 和排第 10 没区别。NDCG 对位置敏感，越靠后惩罚越大。推荐系统用户只看前几条，NDCG 更能反映真实体验。

### Q5: AUC 有什么缺点？
1. 不关心绝对分数值，只关心排序
2. 不区分正样本排第 1 和排第 50 的差异
3. 正负样本比例极端时，AUC 可能虚高

### Q6: NDCG 的位置折扣因子为什么是 1/log2(i+2)？
模拟用户注意力衰减：第 1 位权重 1.0，第 2 位 0.63，第 3 位 0.5，越往后越低。log 函数衰减速度适中，既不像指数衰减那么快，也不像线性衰减那么慢。

### Q7: MRR 和 NDCG 的区别？
MRR 只看第一个正确答案的位置，NDCG 适用于多个正确答案的场景。排序阶段一个用户可能有多个正样本，NDCG 更合适。召回阶段通常只有一个 ground truth，MRR 足够。

### Q8: 召回阶段为什么不看 NDCG？
召回阶段的候选是粗糙的，排序不精确。看 NDCG 没意义，只要正确答案在 top-K 里就行。NDCG 留给排序阶段用。

### Q9: 冷启动用户如何影响指标？
冷启动用户无召回结果，如果跳过不计会高估指标。应该计入 total 但不计 hit，反映系统真实覆盖率。

### Q10: 召回数小于 K 时指标怎么算？
Python 切片 candidates[:k] 不会越界，有多少取多少。指标不会出错，但说明召回覆盖不足，需要加强召回策略。
